## 详情 (Details)
<p>
Shell 是一个右键菜单（上下文菜单）扩展程序，它允许你手动挑选并集成到 Windows 资源管理器右键菜单中的项目，创建自定义命令以访问所有喜爱的网页、文件和文件夹，并直接从右键菜单启动任何应用程序。<br>
它还为你提供了一个便捷的解决方案，用于修改或移除由系统或第三方软件添加的任何右键菜单项。
</p>

## 功能特性 (Features)
* 轻量级、便携且相对易于使用。
* 完全自定义外观。
* 支持添加新的自定义项目（如子菜单、菜单项和分隔符）。
* 修改或删除已存在的项目。
* 支持所有文件系统对象，包括文件、文件夹、桌面和任务栏。
* 支持表达式语法，包含内置函数和预定义变量。
* 支持颜色、字形 (Glyphs)、SVG、嵌入式图标以及图像文件（如 .ico、.png 或 .bmp）。
* 支持搜索和过滤。
* 支持复杂的多级嵌套菜单。
* 支持多列显示。
* 通过纯文本文件即可快速、轻松地进行配置。
* 极低的资源占用。
* 无功能限制。
